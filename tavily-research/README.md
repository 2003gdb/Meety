# Tavily Research

**Owner:** Martin

Researches the user in the background as soon as they sign up, so the agent can ask "Is this you?" without the user typing out their profile.

- Input: the sign-up email and name; LinkedIn is required and X is optional
- Output: a profile summary for the identity check and for Jev prompts
- Can also enrich the attendee profiles scraped by browserbase-luma
